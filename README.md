# PRNG Random Data Generator

This project implements multiple PRNG algorithms in Python:

- XORShift128+
- LFSR
- Linear Congruential Generator (LCG)

The project generates:
- Binary random data (.bin)
- Hexadecimal random data (.hex)

It also includes:
- Entropy testing
- Frequency tests
- Runs tests
- Random bit visualization

## Technologies Used

- Python
- NumPy
- Matplotlib

## Purpose

To analyze randomness quality and compare PRNG algorithms.
